# Screenshots

This folder contains screenshots captured during testing activities.

## Purpose
Screenshots are included to provide visual evidence for:
- Test execution
- Passed test cases
- Failed test cases
- Defect reproduction
- UI validation
- API responses
- Error messages

## Naming Convention
Example formats:
- TC_LOGIN_001.png
- BUG_002_Invalid_Header.png
- UI_Checkout_Page.png

## Best Practices
- Capture clear and readable images
- Highlight important areas when necessary
- Match screenshot names with related test cases or bug reports
- Ensure timestamps and test data remain consistent with reports
