# Bug Reports

This folder contains sample defect reports created during manual testing activities.

## Included
- Functional defects
- UI defects
- Validation defects
- API-related defects

## Bug Report Contents
Each defect report may include:
- Bug ID
- Summary
- Description
- Steps to Reproduce
- Expected Result
- Actual Result
- Severity
- Priority
- Status
- Screenshots

## Tools Used
- Excel
- Jira
- Browser Developer Tools

## Objective
These reports demonstrate:
- Defect identification
- Root cause analysis
- Clear communication
- Documentation skills
- QA reporting standards
