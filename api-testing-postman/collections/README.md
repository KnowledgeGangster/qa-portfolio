# Postman Collections

This folder contains Postman collections used for API testing and automation.

## Included
Collections may contain:
- GET requests
- POST requests
- PUT requests
- DELETE requests
- Authentication requests
- Validation scripts

## Validation Examples
- Status code validation
- Response body validation
- Header validation
- Response time validation
- Schema validation

## Automation
Collections can be executed using:
- Postman Collection Runner
- Newman CLI

## Example Files
- restful-booker-collection.json
- authentication-api-tests.json
- user-management-api-tests.json

## Skills Demonstrated
- API Testing
- REST API Validation
- Automation Scripting
- JSON Handling
- Request Chaining
- Environment Variables
